# Ingot slider: base programs

Everything for the base: programs (.nc), setup sheets (.html), pictures and the STEP. How to set up and run
them is in [../RUN.md](../RUN.md).

Batch order:
1. `base-first.nc` on the first raw blank (op 1 only, left station, G54).
2. `base-cycle.nc` once for every blank after it (op 1 left + op 2 right in one program).
3. `base-last.nc` for the last blank (op 2 only, right station, G55).

Aluminium is still planned on nominal 12.7 × 25.4: measure it first.
