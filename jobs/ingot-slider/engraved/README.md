# Ingot slider: Eclipse engraving option

The normal ingot slider, with a 1st-gen Eclipse in side view engraved 0.3 deep on its top field (wedge nose and
pop-up headlight lid, side glass, doors, crease, ducktail, wheels) instead of the crosshatch. Same tools and
times as the ingot slider. How to run: ../RUN.md. Batch order:

1. `../slider/slider-first.nc` on the first raw blank (op 1 is the same).
2. `engraved-cycle.nc` once for every blank after it.
3. `engraved-last.nc` for the last blank.
